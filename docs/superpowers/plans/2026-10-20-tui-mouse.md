Spec: the owner's request, 2026-10-20 21:5xZ, verbatim: "tui에 mouse interaction기능추가." (add mouse
interaction to the TUI). Scope decided by junyong-dev-bot and announced in Discord thread 1562221945955815556:

## Global Constraints

## Task 1: mouse mirrors of the main view and popup keys

1. Clicking a tab label in `#tabs` switches to that tab (same as `action_tab`).
2. Clicking a row in `#body` moves the cursor to that row (`self.cursor[self.tab]`, same state as up/down).
   Clicking the row that is already selected does what Enter does (`action_open`).
3. The mouse wheel over the pane moves the cursor one row up/down (same as `action_move`).
4. In popups, clicking a `Choice` or `Check` changes it like its space binding and focuses it. `Btn` already clicks.
   List rows in `AccessEdit`/`HostEdit` get the same click-to-select, click-selected-to-act rule only if trivial.
5. Row and tab hit-testing uses a map recorded at render time (body line -> row key, `#tabs` x-span -> tab),
   not layout re-derived in the click handler.

Tests (pilot): tab click switches tab; row click moves the cursor; a second click on the same row opens it;
the wheel moves the cursor; a Choice click turns it; a drag/selection does not move the cursor (or, if the
pilot cannot drag, the guard is tested directly).
